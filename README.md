## 📌 Περιγραφή Έργου

Το παρόν project αναπτύχθηκε στα πλαίσια του μαθήματος **«Μέθοδοι Επίλυσης με Η/Υ»**. Αντικείμενο της εργασίας είναι η προσομοίωση της βιολογικής αποκατάστασης ενός ρυπασμένου υδροφορέα από **βενζόλιο** μέσω της εξίσωσης **Monod**:

$$r_S = \frac{dS}{dt} = -\frac{\mu_{max}}{Y} \frac{S}{K_S + S} X_a$$

### 🎯 Βασικά Ερωτήματα
1. **Ερώτημα 1 (Φυσική Εξασθένηση):** Υπολογισμός του χρόνου $T_{no}$ (ημέρες) για τη μείωση της συγκέντρωσης από $S_0$ στο όριο πόσιμου νερού $S_{MCL}$ χωρίς παρέμβαση.
2. **Ερώτημα 2 (Ενισχυμένη Απομάκρυνση):** Υπολογισμός της νέας απαιτούμενης συγκέντρωσης μικροοργανισμών $X_{a,n}$ για επίτευξη του στόχου σε καθορισμένο χρόνο $T_b < T_{no}$.
